## 7. PostgreSQL SQL Inspection Queries

Useful verification queries in `psql` or `pgAdmin`:

```sql
-- View all migrated tables
\dt

-- Inspect appointments with doctor and department details
SELECT
    a.id,
    a.patient_id,
    u.full_name AS patient_name,
    a.doctor_id,
    doc_user.full_name AS doctor_name,
    a.department_id,
    d.name AS department_name,
    a.appointment_date,
    a.time_slot,
    a.status
FROM appointments a
LEFT JOIN users u ON a.patient_id = u.id
LEFT JOIN doctors doc ON a.doctor_id = doc.id
LEFT JOIN users doc_user ON doc.user_id = doc_user.id
LEFT JOIN departments d ON a.department_id = d.id
ORDER BY a.id DESC;
```
